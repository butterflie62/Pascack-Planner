# Pascack Planner

A student-friendly course-planning website for Pascack Valley Regional High School District.

The home page links to the weekly schedule, interest explorer, course catalog, electives and credit types, four-year road map, and student profile. The profile keeps a graduation year, current grade, 8th-grade math information, and completed/current/planned classes with grades. Students can save a transcript file locally in the browser; it is not uploaded to a server or automatically read.

Department road maps use the course catalog's grade and prerequisite notes and let students save future course options by grade. Schedule, profile, road-map, and interest data stay in the browser. Graduation credit totals require students to enter course credits and requirement categories; the initial values are estimates and should be confirmed with a school counselor.
